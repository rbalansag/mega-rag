# 🚀 Mega RAG: The Universal Developer & AI Scaffolding Engine

> **A single command to scaffold production-grade applications with embedded AI coding guardrails (`.cursor/rules/*.mdc`), machine documentation maps (`llms.txt`), and domain-specific business overlays.**

## 📌 Features
- ⚡ **Branching CLI Initializer**: Interactive CLI (`npx create-mega-app`) that adapts questions based on platform (Web, Mobile, Backend, Game Engine).
- 🤖 **Embedded AI Guardrails**: Automatic injection of `.cursor/rules/*.mdc`, `AGENTS.md`, and `llms.txt` context feeds.
- 📦 **Updatable Versioned SDK**: Keep existing projects in sync by simply updating `@mega-rag/rules` in `package.json`.
- 🏢 **Domain Overlays**: Pre-built logic modules for B2B SaaS, E-Commerce, Uber H3 Logistics, and Game Telemetry.
